# MapViewer 프로젝트 검색 기능 문서

## 개요
MapViewer의 프로젝트 검색 기능은 도면 데이터 기반의 GIS 분석 및 특수 문법을 처리하여 사용자가 도면 내 포인트, 거리, 교차점 등을 검색하고 분석할 수 있는 기능을 제공합니다.

## 파일 구조

### 1. search_engine.js
**역할**: 검색 기능의 진입점 및 UI 관리

#### 주요 함수
- `searchPoints()`: 프로젝트 검색의 메인 진입점
  - 프로젝트 선택 상태 확인
  - GIS 검색 모달 열기
- `updateSearchButtonUI()`: 검색 버튼 UI 업데이트
  - 버튼 텍스트를 '프로젝트 검색'으로 통일
  - 프로젝트 선택 여부와 관계없이 버튼 노출

### 2. search_db.js
**역할**: 공통 검색 유틸리티 및 텍스트 매칭 엔진

#### 주요 함수
- `sanitizeSearchText(str, isQuery)`: 검색어 정제
  - 불필요한 조사/접미사 제거
  - 특수문자 정제 (%%[cdp], [, ], /, \, -, _ 등)
  - 소문자 변환 및 공백 제거
- `matchComplexQuery(targetText, query)`: 복합 검색 문법 매칭
  - **AND 연산**: 공백으로 구분 (예: "제수변 하단")
  - **OR 연산**: `&` 기호 사용 (예: "제수변&하단")
  - **NOT 연산**: `!` 기호 사용 (예: "제수변!하단")
  - 점수 기반 매칭 (AND 우선순위)

### 3. search_gis.js
**역할**: GIS 문법 해석 및 공간 분석 실행

#### 주요 함수

##### UI 관련
- `openGisSearchModal()`: GIS 검색 모달 생성 및 표시
  - 검색 입력창
  - 단축키 버튼 ([Layer], [사진], [거리], [좌표], [교차], 📍, 📋)
  - 도움말 토글 기능
  - 레이어 선택 오버레이

##### 문법 해석 및 실행
- `executeGisSearch(searchTerm, isSubTask)`: GIS 문법 메인 실행 함수
  - 한글 명령어 정규화 ([분석] → 📋, [지도] → 📍)
  - AI 자연어 분석 시도 (문법 기호가 없는 경우)
  - 다중 작업 오케스트레이션 (`&&` 기호 처리)
  - 분석 접미사 기반 기능 분기

##### 검색 및 필터링
- `filterFeaturesByComplexQuery(searchTerm, geometryType)`: 복합 쿼리 필터링
  - 레이어별 필터링 지원
  - 속성값 통합 검색
  - GeoJSON 및 Map 소스 지원
- `executePointSearch(searchTerm, useBookmark, isAudit, isSubTask)`: 포인트 검색 실행
  - 복합 쿼리 필터링 적용
  - 지도 북마크 및 리스트 출력

##### 분석 기능
- `analyzePhotoMismatch(targetLayer, useBookmark, isAudit, isSubTask)`: 사진 매칭 분석
  - 레이어 포인트와 사진 저장소 비교
  - 미스매칭 항목 식별
  - 클라우드 사진 데이터 동기화
- `analyzePointToPointDistance(pointNames, useBookmark, isAudit, isSubTask)`: 포인트 간 거리 계산
  - 여러 포인트 연결 경로 거리 산출
  - PostGIS 공간 연산 활용
  - 구간별 경로 정보 제공
- `analyzeTotalDistance(targetLayer, useBookmark, isAudit, isSubTask)`: 레이어 전체 거리 산출
  - 선형 객체 연장 합산
  - 로컬 속성 우선 활용 (성능 최적화)
  - 폴리곤 데이터 제외 처리
  - 청크 단위 대용량 처리
- `analyzeDistanceGap(targetLayer, threshold, useBookmark, isAudit)`: 거리 이격 분석
  - 임계값 초과 포인트 간격 식별
  - 최대 100개 포인트 분석
  - 이격 구간 지도 표시
- `analyzeIntersections(targetLayer, useBookmark, isAudit, otherLayers, isSubTask)`: 선 레이어 교차 분석
  - 다중 레이어 교차점 식별
  - 특정 레이어 간 교차 분석 지원
  - PostGIS 교차 분석 활용
- `showPointInfo(query, isSubTask)`: 포인트 상세 좌표 조회
  - TM 좌표계 정보 출력
  - 높이(Z) 정보 포함
  - 테이블 형태 상세 정보

##### 유틸리티
- `checkPhotoMatch(pointText, photoFileName)`: 사진 파일명 매칭 규칙
  - CAD 제어코드 제거
  - 하이픈 구분 ID 추출
  - 정규식 기반 정확 매칭
- `renderGisResultList(searchTerm, matches, useBookmark, isSubTask)`: 결과 리스트 모달 렌더링
  - 검색 결과 테이블 출력
  - 위치 이동 버튼 제공

## GIS 문법 체계

### 기본 연산자
- **`&`**: OR 연산 (또는)
- **`공백`**: AND 연산 (그리고)
- **`!`**: NOT 연산 (검색 제외)

### 분석 접미사
- **`[거리]`**: 연장/거리 계산
- **`[교차]`**: 선 레이어 교차 분석
- **`[사진]`**: 사진 매칭 분석
- **`[좌표]`**: 상세 좌표 조회
- **`[Layer]`**: 레이어 선택 (단축키)

### 출력 형식
- **`📍`**: 지도 마커 표시 (북마크)
- **`📋`**: 분석 리포트 출력 (리스트)

### 특수 문법
- **`~`**: 도상 거리 (지표연결)
  - 예: `A~B[거리]📋` (A와 B 사이 거리 계산)
- **`&&`**: 다중 질문 연결 (서로 다른 질문 동시 실행)
  - 예: `[GPR지역][거리]📋 && 제수변100📋` (GPR지역 거리 + 제수변100 포인트 개수)
- **`+`**: 합산 연결 (동일한 분석 결과 합산)
  - 예: `[GPR지역][거리]📋 + [상수관망도][거리]📋` (두 레이어 거리 합산)
- **`^`**: 거리 임계값 지정
  - 예: `제수변^[거리]>10` (10m 초과 이격 분석)

### 한글 명령어 (AI 변환 지원)
- **`[분석]`**: 📋로 자동 변환
- **`[지도]`**: 📍로 자동 변환

## 사용 예시

### 기본 검색
```
제수변100📍           # 전체 포인트 속성값에서 "제수변100" 포함된 것 지도 표시
[제수변]📍            # 제수변 레이어의 모든 포인트 지도 표시
제수변!하단📋         # 전체 포인트에서 "제수변" 포함, "하단" 제외 리스트
[제수변]100📍         # 제수변 레이어에서 "100" 포함된 포인트 지도 표시
```

### 거리 분석
```
[제수변][거리]📋                    # 제수변 레이어 전체 연장
260530-01~260530-02[거리]📋      # 두 포인트 간 거리 (텍스트 기반 검색)
[제수변]^[거리]>5📍               # 제수변 레이어 5m 초과 이격 분석
```

### 사진 매칭
```
[제수변][사진]📋          # 제수변 레이어 사진 매칭 분석
```

### 교차 분석
```
[제수변][교차]📋                      # 제수변 레이어와 전체 레이어 교차
[제수변][배관][교차]📋             # 제수변과 배관 레이어 교차
```

### 좌표 조회
```
260530-01[좌표]📋        # 특정 포인트 좌표 상세 정보 (텍스트 기반 검색)
[제수변][좌표]📋           # 제수변 레이어 전체 좌표
```

### 다중 작업
```
[GPR지역][거리]📋 && 제수변100📋     # GPR지역 거리 계산 + 제수변100 포인트 개수 (서로 다른 질문)
[제수변][거리]📋 && [제수변][사진]📋  # 제수변 거리와 사진 매칭 동시 분석 (개별 결과)
[GPR지역][거리]📋 + [상수관망도][거리]📋  # 두 레이어 거리 합산 (총합계 출력)
```

**연산자 동작 방식**
- **`&&` (다중 질문)**: 서로 다른 종류의 질문을 동시에 실행하고 개별 결과 출력
- **`+` (합산)**: 동일한 분석(거리 등) 결과를 합산하여 총합계 출력

### AI 자연어 처리
```
제수변 레이어의 전체 길이를 알려줘    # AI가 자동으로 문법 변환
제수변 레이어와 배관 레이어의 교차점 찾아줘   # AI가 자동으로 문법 변환
```

### AI 복합 계산 처리
- **다중 레이어 거리 합산**: AI가 "와"를 "+"로 인식하여 자동 변환 (동일한 분석인 경우)
  - 예: "GPR지역 레이어와 상수관망도 레이어의 전체 길이를 합산해줘"
  - 변환: `[GPR지역][거리]📋 + [상수관망도][거리]📋`
  - 결과: 두 레이어 거리 합산 및 총합계 출력
- **다중 질문**: 서로 다른 종류의 질문은 "&&"로 변환
  - 예: "GPR지역 거리랑 제수변100 포인트 개수 알려줘"
  - 변환: `[GPR지역][거리]📋 && 제수변100📋`
- **주의사항**: "와"가 "교차"와 함께 언급되지 않고 동일한 분석을 여러 대상에 적용하는 경우 "+"로 변환됩니다.

## AI 인식 가능한 기능

### 자연어 처리
- 문법 기호(📍, 📋)가 없는 경우 AI 자연어 분석 자동 시도
- 현재 도면의 레이어 목록을 맥락으로 제공
- `translate_gis` 모드를 통한 GIS 문법 변환

### AI 변환 예시
- "제수변 레이어 길이" → "[제수변][거리]📋"
- "제수변과 배관 교차" → "[제수변][배관][교차]📋"
- "제수변 텍스트 포인트" → "제수변📍" (전체 포인트 속성값 검색)
- "제수변 레이어 사진 매칭" → "[제수변][사진]📋"

## 데이터 흐름

### 검색 실행 과정
1. 사용자가 검색어 입력 및 실행
2. `executeGisSearch()` 함수 호출
3. 문법 기호 확인 및 정규화
4. AI 자연어 분석 (필요시)
5. 다중 작업 분리 (`&&` 처리)
6. GeoJSON 데이터 로드
7. 분석 접미사 기반 기능 분기
8. 복합 쿼리 필터링 적용
9. PostGIS 공간 연산 (필요시)
10. 결과 렌더링 (지도/리스트)

### 공간 연산
- **PostGIS RPC 함수** 활용:
  - `calculate_line_lengths`: 선형 객체 길이 계산
  - `analyze_intersections`: 선 레이어 교차 분석
- **좌표계**: 프로젝트별 `source_crs` 적용
- **대용량 처리**: 청크 단위 (500개) 분할 처리

## 성능 최적화

### 로컬 속성 우선
- GeoJSON에 이미 계산된 거리 속성이 있으면 로컬에서 즉시 합산
- 다양한 속성명 대응 (length_m, length, Length, LENGTH, LEN, len, dist, distance)

### 데이터 필터링
- 복합 쿼리 필터링으로 불필요한 데이터 제외
- 특정 레이어 지정 시 전송 데이터 크기 감소

### 청크 처리
- 대용량 데이터 시 500개 단위 분할 처리
- 진행 상태 사용자 알림

## 의존성

### 내부 모듈
- `core.js`: 상태 관리, Supabase 호출, AI 엣지 호출, 알림
- `viewers.js`: CAD 레이어, 검색 결과 렌더링, 지도 표시, 사진 로드
- `ai.js`: AI 응답 모달, 메시지 모달

### 외부 서비스
- **Supabase**: PostGIS 공간 연산, 데이터 저장소
- **AI Edge**: 자연어 GIS 문법 변환

## 제한 사항

### 거리 이격 분석
- 최대 100개 포인트로 제한
- 포인트 간 조합 계산으로 인한 성능 고려

### 사진 매칭
- 클라우드 사진 데이터 동기화 필요
- 파일명 형식: `000000-00` 패턴 기반 매칭

- 선형 객체(LineString)만 지원
- 폴리곤은 외곽선만 추출하여 분석
